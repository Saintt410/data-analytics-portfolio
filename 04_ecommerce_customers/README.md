# E-commerce Customer Analysis

**Business problem:** Most buyers never return — how do customers behave and how can we grow repeat purchases and order value?

**Required CSV columns:** `order_id, customer_id, order_date, amount`

Run: `python 04_ecommerce_customers/analysis.py [--data your.csv]` → results printed and saved to `04_ecommerce_customers/outputs/`.

The script prints *What the data tells me* findings and *What the business should do next* recommendations computed from the data.
