# Employee Attrition Analysis

**Business problem:** Turnover is costly — which factors are associated with higher attrition?

**Required CSV columns:** `employee_id, age, department, job_role, overtime, monthly_income, job_satisfaction, years_at_company, attrition (0/1)`

Run: `python 05_employee_attrition/analysis.py [--data your.csv]` → results printed and saved to `05_employee_attrition/outputs/`.

The script prints *What the data tells me* findings and *What the business should do next* recommendations computed from the data.
